宮古島の後に東京へ戻り、夏のトレーニング量をしっかり積むつもりだったのですが、足の指を骨折してしまい、1 ヶ月半ほどほぼ走れない状態になりました。7 月末には台湾に一時帰国したのですが、台湾に帰るとなぜか毎回太ります。戻ってきたら仕事も特に忙しく、トレーニングのリズムはずっと途切れがちでした。バイクはなんとか維持できたものの、ランは完全に止まっていました。体重もこの期間の状態を正直に反映して、増えました。現実は厳しいです。

というわけで、今回の洞爺湖は B レースの気持ちで臨みます。厳しい目標は設定せず、完走できれば十分。ついでに北海道の涼しい風に当たって美味しいものを食べる、宮古島の後の気楽な出場という位置づけです。

エントリーの時は A Type と B Type で迷いましたが、最終的に距離の短い B Type を選びました。主な理由は、10 月の 99T（70.3 ディスタンス）が今シーズンの A レースだからです。8 月のこのレースがその準備に影響するのは避けたい。ここで無理に A Type の 137km バイクに出ると回復に時間がかかり、かえってその後のトレーニング時間を削ってしまいます。なので今回は参加すること自体が目的で、北海道のコースと景色を体験して、レース後はダメージなくそのままトレーニングプランに復帰する、という計画です。

## レース概要

[北海道トライアスロン](https://hokkaido-triathlon.jp/)は 8 月 23 日（日）朝 7:00 スタート、会場は洞爺湖周辺で、コースは羊蹄山の山麓まで延びています。私がエントリーしたのは B Type です：

| 種目 | 距離 |
|------|------|
| スイム | 2km（洞爺湖、淡水） |
| バイク | 91.7km |
| ラン | 23.1km |
| 合計 | 116.8km |

![洞爺湖（Photo: [663highland](https://commons.wikimedia.org/wiki/File:130922_Lake_Toya_Toyako_Hokkaido_Japan03s3.jpg), [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/)、トリミング・圧縮）](hero.webp)

スイムは洞爺湖の中を泳ぎます。スタートは珍小島のビーチから。淡水湖でのスイムは海とはかなり感覚が違い、浮力は小さいものの、波や塩水の心配がないので一長一短です。ランは湖畔沿いで、ほぼフラットで木陰も多いとのこと。8 月の北海道ならそこまで暑くはならないはずです。

宮古島と比べると距離はだいぶ短く（116.8km vs 168km）、スイムは 1km 短く、バイクは約 30km 短く、ランはフルマラソンから 23km になりました。

### バイクコース

まずルートを引いて確認してみました。B Type は 91.95km、獲得標高 904m です：

![B Type バイクコースと標高プロファイル。まず洞爺湖を一周し、その後北側の山エリアへ](cycling_route.webp)

標高プロファイルは読みやすい形です。前半は洞爺湖沿いで、湖面の標高は 84m ほどなので基本的にフラット。25km あたりから北側の山エリアに入り、40km 付近で 3 つの登りが連続して最高点は約 300m。最後の 20km あまりは湖畔のフラットな道に戻ります。

904m の獲得標高は 3 つの区間に分散していて、1 区間あたりの標高差は 200m 程度。なのでキツい登りはありませんが、連続するアップダウンはフラットなコースよりペーシングを乱します。宮古島は 976m が 123km の小さな丘に分散していたのに対し、ここは 904m が中間の 40km に集中しているので、性質がかなり違います。

## 現在のコンディション（正直に）

最大の変数は足指の骨折です。この半年の月間ラン距離を出してみると、落ち込みは一目瞭然です：

![直近半年の月間ラン距離。6〜7 月はほぼ停止状態](running_stats.webp)

| 月 | ラン距離 |
|------|------|
| 3 月 | 149.6 km |
| 4 月 | 131.6 km（宮古島レース月） |
| 5 月 | 88.3 km |
| 6 月 | 37.5 km |
| 7 月 | 23.6 km |
| 8 月（8/13 時点） | 45.2 km |

3〜4 月の宮古島準備期は月間 130〜150km 走っていましたが、5 月から落ち始め、骨折後の 6〜7 月は 20〜30km まで低下。まるまる 1 ヶ月半、実質的に走れていなかったことになります。8 月に骨がくっついてから少しずつ戻して、現時点で 45.2km です。

とはいえ骨折した以上、これは想定内で驚くことではありません。コーチが怪我に合わせてプランを調整し、ランは一旦停止、重心をスイムとバイクに移して、やるべき対処はすべてやりました。あとは治るのを待つだけでした。バイクの量は維持できたので、FTP はそれほど落ちていないはずです。brick run もやっていませんが、もともとレース前の数週間にしか入れないメニューなので、影響は思ったほど大きくありません。一番自信がないのは、純粋なランの持久力です。

スイムには新しい変数があります。この期間に日本でマンツーマンのスイムレッスンを受けて、フォームを調整中なのですが、まだ体に染み付いていません。フォーム改造の移行期に速度が少し落ちるのは正常で、実際いま少しだけ遅くなっています。今回のレースで、調整がどこまで進んだか分かるはずです。

7 月末の台湾滞在中も完全に止まっていたわけではなく、やるべき練習はやっていました。ただ量は減りましたし、台湾の食べ物が美味しすぎました。戻ってからリズムを取り戻すのに時間がかかり、体重は少し増え、体感も宮古島の前より一段落ちています。

現状をまとめると：

- **スイム**：練習は継続中だが、フォーム改造中で速度は一時的に低下
- **バイク**：3 種目の中で一番状態がいい。少なくとも乗り続けられた
- **ラン**：1 ヶ月半のブランクから戻ったばかりで、ロング走はゼロ

## コーチからのペース指示

レース前にコーチと相談して、もらった指示はこんな感じです：

| 種目 | 指示 |
|------|------|
| スイム 2km | 7〜8 割の力で、安定して泳ぎ切る |
| バイク 91.7km | 心拍 155-165、パワー 70-75% FTP |
| ラン 23.1km | 1 周目心拍 155-160、2 周目 160-165、ペース 5:00-5:30/km |

### スイム（2km）

7〜8 割の力で、スタート位置は争わない。フォームが調整期にある以上、もともと速度を求めるべきではなく、重要なのは新しい動きをレースの状況で一通り試して、どれくらい維持できるか確認することです。宮古島ではスイムアップ時に心拍が 185 まで跳ね上がったので、今回はもう少しコントロールしたいところです。

### バイク（91.7km）

コースの起伏が大きくパワーは常に上下するので、コーチの指示は心拍 155-165 をメインに、パワー 70-75% FTP をサブにするというものです。これは宮古島のワット数を見つめながら走るやり方とは違います。宮古島のコースはフラットでパワーをコントロールしやすかったのですが、ここは中盤に 3 つの登りが連続するので、平均パワーを無理に揃えようとすると、登りで無駄な高出力を絞り出すことになります。

実際の走り方としては、登りで突っ込まない。速度が落ちてもいいので心拍を 165 以上に上げず、下りで回収する。最後の 20km、湖畔のフラット区間に戻ったら意識的にもう少し抑えて、脚をランに残します。

### ラン（23.1km）

ランは湖畔を 2 周するコースなので、コーチは心拍を 2 段階に分けました。1 周目 155-160、2 周目 160-165、ペースは 5:00-5:30/km です。

ここが今回のレース最大の疑問符です。5:00-5:30 は実は宮古島のフルマラソンの 5:37 より速く、通常のコンディションなら攻めた設定ではないのですが、1 ヶ月半のブランクから戻ったばかりでロング走はゼロ。2 周目を持たせられるか、正直自信がありません。

計画としては、1 周目は心拍に厳密に従い、脚に余裕があっても上げない。2 周目は状況を見て上げるか判断します。筋肉が持たなければ、宮古島の経験どおりに対処して、安全な完走を最優先にします。

## 補給

補給戦略はほぼ宮古島の経験をそのまま引き継ぎ、炭水化物のターゲットは 80-90g/hr を維持します。バイクの距離が宮古島より短いので、バイク上の補給量は比較的余裕があります。宮古島のボトル漏れ事件は記憶に新しいので、今回はスタート前に必ず入念にチェックします。

ランは 23km だけなので、5:00-5:30 のペースなら 2 時間ちょっと。補給のプレッシャーはフルマラソンよりずっと軽く、ジェルを数本とエイドの水で十分なはずです。

## このレースへの期待

正直なところ、今の状態で 117km のトライアスロンに出るにしては、精神的なプレッシャーは宮古島よりずっと小さいです。宮古島は A レースで、レース前に完走タイムを設定し、レース後には種目ごとに達成度をレビューしました。今回のペース指示は実行の参考であって、達成すべきターゲットではありません。そのとおり走れればもちろん良いし、届かなくても問題なし。参加すること自体が目的で、北海道の夏を感じて、洞爺湖で泳いで、羊蹄山の景色を見ながら走って、レースを完成させる。それだけです。

足指の回復はまずまずなので、レース当日には 23km を安定して走り切れることを願っています。本当にダメなら、歩いてゴールしても完走は完走です。

本当に勝負するのは 10 月の 99T です。今回はレース復帰のウォームアップとして、スイムの新フォームと骨折後のラン感覚をまとめて試す機会にします。
